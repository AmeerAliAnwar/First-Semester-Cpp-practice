# First Semester C++ Practice

Was going through my laptop storage and stumbled upon some of my first-semester C++ work.

Decided to push it to GitHub and keep a little record of where my programming journey started.

Nothing fancy, just the basics, practice problems, and a few memories from the early days of learning to code.

Everyone starts somewhere.

## What's in here

A folder for each stage of the semester, roughly ordered from the very first programs to the later object-oriented material. Every file was added as its own commit, dated when I originally wrote it, so the history is a small timeline of the whole journey.

| Folder | Topics covered |
| --- | --- |
| `01_Basics/` | Variables, data types, input/output, arithmetic, swapping numbers, simple calculators |
| `02_Conditionals/` | if, else if, switch, grades and percentages, leap year, character checks |
| `03_Loops/` | for and while loops, number series, tables, primes, factorials, min/max of a series |
| `04_Patterns/` | Star and number patterns, pyramids, diamonds, boxes |
| `05_Arrays/` | 1D and 2D arrays, matrices, searching, sorting algorithms |
| `06_Functions/` | User-defined functions with and without parameters/return values |
| `07_Strings/` | String input with getline, string tasks, case conversion, ASCII |
| `08_Structs/` | Structures, nested structs, structs with member functions |
| `09_Classes_OOP/` | Classes, encapsulation, inheritance, operator overloading |
| `10_File_Handling/` | Reading from and writing to files |

## Notes

- Only the source files are here. The compiled `.exe` files were left behind, and they are git-ignored anyway.
- These are learning programs, so expect simple solutions, a few spelling typos in the file names, and plenty of rough edges. That is part of the charm.
- Everything was written in standard C++ and compiled with g++ during the semester, but any C++ compiler will do.

## Running one

```bash
g++ "01_Basics/ADDITION.cpp" -o addition
./addition
```

Compile it, run it, and you get the same little console program I was proud of back then.
